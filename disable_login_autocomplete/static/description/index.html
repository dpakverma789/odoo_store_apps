Disable Login Autocomplete

Enhance the security of your Odoo login page by preventing browsers from saving or auto-filling credentials.

🔒 Why This Module?

Modern browsers automatically store login credentials and suggest them during login. While convenient, this behavior can be risky in environments where multiple users share the same computer.

  • Shared office computers
  • Public workstations
  • Call center environments
  • Devices used by multiple employees

This module disables browser autocomplete and password autofill on the Odoo login form, reducing the risk of credential exposure.

✨ Key Features

  • Disable browser password autofill
  • Disable username autocomplete
  • Prevent credential storage in browser
  • Lightweight and secure implementation
  • No impact on Odoo authentication logic
  • Compatible with Odoo 18

⚙️ How It Works

The module extends the default login template and adds security attributes to input fields. 

autocomplete="off"
autocomplete="new-password"

These attributes instruct modern browsers not to store or suggest saved credentials.

📦 Installation

  1. Download the module
  2. Place it inside your Odoo addons directory
  3. Update Apps List
  4. Search for Disable Login Autocomplete
  5. Click Install
