Odoo Field Syntax Generator
Generate Python and XML field syntax instantly for faster Odoo development

🚀 Overview

The Odoo Field Syntax Generator helps developers quickly generate Odoo Python field definitions and XML view syntax from a simple variable list.

Instead of writing repetitive boilerplate code, simply enter variables like:

name.c age.i salary.f date_of_birth.d

The module instantly generates ready-to-copy Python and XML code.

✨ Features

✅ Generate Python fields syntax automatically
✅ Generate XML form/list field tags
✅ Supports most Odoo field types
✅ Reduces repetitive coding time
✅ Developer productivity tool

📋 Supported Field Types

c → Char i → Integer f → Float d → Date dt → Datetime bi → Binary s → Selection b → Boolean mo → Many2one om → One2many mm → Many2many
